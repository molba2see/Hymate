# data

앱의 도메인 모델과 정적 콘텐츠.

| 파일 | 내용 |
|---|---|
| `HyData.kt` | 가이드 20종 정의(판정 유형·레벨·근거 법령), 차량 신호 모델(`Vehicle`), 퀘스트 모델(`Quest`), 주차 중 실습 단계(`PStep`), 라이선스 단계표 |
| `Growth.kt` | 주행 결과 → 성장 반영 순수 함수. 졸업(Lv1~2는 1회, Lv3+는 3지점)·복귀·XP 계산. `GrowthTest`로 검증 |
| `RouteGeo.kt` | 데모 경로(국민대→양재)의 위경도 앵커와 GPS↔경로거리 변환 |
| `DemoQuestResults.kt` | 발표용 데모 주행의 결과 생성 |

판정·성장 로직은 Android 의존성이 없어 로컬 단위 테스트로 돌아갑니다.
