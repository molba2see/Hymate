# 실제 도로 길찾기 · 재탐색 테스트

지도는 MapLibre Native + OpenStreetMap, 길찾기는 OSRM Route API를 사용한다. API 키 없이 동작하며 인터넷이 필요하다. 목적지는 기존 현대자동차 양재 본사 좌표다. 경로 선·다음 회전·거리·ETA는 같은 탐색 응답으로 만든다. 18개 손도화 앵커와 고정 21.4km 안내는 주행 화면에서 사용하지 않는다.

## 데모: Location 조작 없이 출발

디버그 Android/Pleos 에뮬레이터의 기본값은 **국민대 출발 데모**다.
1. 새 주행을 시작하면 국민대 정문 진입 도로에서 양재까지 자동차 경로를 탐색한다.
2. 탐색이 끝나면 0m에서 시작해 실제 수신 차속 × 경과 시간만큼 도로 폴리라인을 따라 이동한다.
3. 정지·P·후진·차속 유실 시 전진하지 않는다. 네트워크 탐색 중 이동량은 완료 후 몰아서 반영하지 않는다.
4. Extended Controls의 저장된 GPS는 데모 진행도에 개입하지 않는다. 시스템 GPS는 변경하지 않는다.
5. 흰 도착 카드에는 탐색된 도로 거리와 구간별 예상 시간이 표시된다. 실시간 교통·신호 대기는 반영하지 않는다.

## 실제 GPS: 자동 재탐색

주차(P) 후 **동승 설정 → 지도 위치 · 다음 주행 → 실제 GPS**를 고르고 새 주행을 시작한다. 실차·릴리스 빌드는 실제 GPS가 기본이다.
- FusedLocation 1.1.3 / FUSED_LOCATION 런타임 권한으로 받은 현재 위치에서 양재까지 탐색한다.
- GPS를 탐색된 도로에 투영한다. 35m 이내면 도로 위 점을, 그 밖이면 원래 좌표를 표시한다.
- 60m 초과 이탈이 두 번 이상 관측되고 3초 이상 이어지면 현재 위치에서 재탐색한다. 최초 요청점과 도로의 진입 오프셋은 진입 전까지만 허용한다.
- 재탐색은 15초 간격을 지키고 중복 요청하지 않는다. 실패 시 30초 후 재시도하며, 기존 경로는 남기되 오래된 회전 안내·ETA는 숨긴다.
- GPS가 10초 이상 갱신되지 않으면 안내를 대기 상태로 바꾼다.
- 새 경로가 오면 경로 선·회전·잔여 거리·시간을 함께 교체한다. 새 주행/종료로 취소된 요청은 늦게 도착해도 반영하지 않는다.
- 도착은 경로 끝 40m 이내이면서 실제 종점 40m 안의 GPS가 두 번 연속 관측됐을 때 판정한다.
- 에뮬레이터에서 GPS 검증할 때만 Virtual Console 또는 Extended Controls에서 좌표를 이동한다. 기존 docs/demo-route.gpx는 손도화 경로라 이탈 시험에만 사용한다. 실제 도로 데모는 별도 GPX가 필요 없다.

재탐색 검증 예: 서울의 도로 좌표에서 GPS 주행 시작 → 안내 중 다른 도로로 100m 이상 이동 → 3초 이상 유지 → 재탐색 상태와 새로운 경로·회전·ETA 확인. GPS 한 번의 튐으로는 재탐색하지 않아야 한다.

## 차량 퀘스트

출발 전 목록과 리포트에 같은 가이드를 유지한다. 리포트는 TOP 3 대신 전체 목록을 보여주며 자동 판정, 직접 체크, 해당 없음을 구분한다. 차량이 실제로 미지원인 기능은 제외한다.

- **차량 자동 체크 5종**: 출발 시 운전석 안전벨트 체결, 출발 10초 후 전조등 AUTO, 실제 차속 변화의 급출발·급제동, 동의한 경우 와이퍼 10초 이상 작동 중 실제 전조등 점등. AUTO 스위치 위치와 실제 점등은 별도 데이터다.
- **실제 경로 자동 체크 4종**: 회전·합류 지점의 30m 전 방향지시등, 회전 전후 15m의 관측 최고 속도, 실제로 켰던 방향지시등의 회전 후 해제. 회전 속도 20km/h와 가감속 기준은 앱 가이드 기준이다. 재탐색하면 미완료 지점만 새 경로에 연결하고 완료 기록은 보존한다.
- **주차 후 직접 체크**: 어린이보호구역·제한속도·터널·신호 색·차로 위치 등 현재 지도/센서에서 확인할 수 없는 항목. 일반 크루즈 ACTIVE 관측은 표시하되 NSCC 2 사용을 증명하지 않으므로 사용 여부는 직접 확인한다.
- 위치가 튀거나 관측이 끊긴 자동 항목, 해당 이벤트를 관측하지 못한 항목도 리포트에서 직접 체크로 전환한다. 주차 후 상세 항목에서 **지켰어요 / 못 지켰어요 / 해당 없음**으로 답한다. 직접 답한 자동 가이드는 자동 성공·실패 및 자동 졸업/XP로 계산하지 않는다. 경험 가이드의 직접 사용 확인은 기존 경험 기록 규칙을 따른다.
- 상황 가이드 동의를 거절하면 항목을 지우지 않고 제외 이유를 남긴다. 경로에 판정 지점이 없거나 켜지 않은 방향지시등의 해제처럼 적용할 수 없는 항목도 이유를 표시한다.

검증 순서:
1. 주행 전 각 가이드 아래 자동/직접 체크 방식을 확인한다.
2. 실제 차속과 방향지시등을 바꾸며 경로의 회전·합류 지점을 통과한다. 늦게 켠 경우와 30m 이전에 켠 경우를 비교한다.
3. 완만한 출발/정지와 급격한 차속 변화를 각각 관측해 결과가 달라지는지 확인한다. 단순히 브레이크 페달을 눌렀다는 이유만으로 급제동 처리하지 않는다.
4. 주차·주행 종료 후 전체 목록을 열어 자동 근거와 확인 대기 항목을 확인하고 직접 체크 세 버튼을 시험한다. 홈의 전체/직접 체크/확인 대기 건수도 확인한다.
5. GPS 도약·차속 유실·재탐색 중 지나친 지점이 자동 성공으로 처리되지 않는지 확인한다.

새 경로에는 기존 데모의 교차로·어린이보호구역·제한속도 위치를 적용하지 않는다. OSRM 경로 탐색만으로 제한속도·신호 색·차로 단위 안전 판정을 할 수 없다.

## 발표용 80% 성공 버튼

디버그 에뮬레이터에서 **퀘스트 시작 → 주행 화면 오른쪽 위 ‘데모 · 80% 성공 리포트’**를 누른다. P 상태에서 조작한다. 실제 GPS 모드를 선택해도 발표용 버튼은 사용할 수 있다. 릴리스 빌드와 실차에서는 제공하지 않는다.

- 실제 차량 데이터·주행 거리·GPS는 변경하지 않고, 가이드별 한 건씩 약 80%를 성공/기록/경험으로 생성해 즉시 리포트로 이동한다. 나머지는 놓침/미수행이다. 경로 탐색 완료를 기다릴 필요 없다.
- 리포트·최근 주행·라이선스 화면은 일반 결과 문구로 표시한다. 생성 여부와 원본 근거는 내부 기록에 유지하며, 생성 버튼에는 데모임을 표시한다. 상황 가이드 결과도 실제 우천 관측이 아닌 생성 결과다.
- **확인하고 마치기**를 누르면 기존 XP·졸업·라이선스 임계값을 그대로 적용한다. 기본 첫 주행 프로필은 L0 발급 흐름을 볼 수 있다. 재출발 후 다시 눌러 후속 주행을 보여줄 수 있다.
- 실측 퀘스트는 기존 판정 흐름을 유지한다. 데모 결과는 운전자 직접 체크와 별개다.
- 운전석 안전벨트는 Pleos Seat의 `getCurrentSeatBeltBuckledState` 및 `SeatBeltBuckledStateListener`로 실제 체결 여부를 읽는다. 읽기 권한 `pleos.car.permission.CAR_SEATS`만 사용한다. 주행 전 가이드와 주행 화면에 **수신 대기 / 체결 / 해제**를 표시한다. 기존 Safety의 미착용 경고 API는 현재 에뮬레이터에서 미지원이므로 사용하지 않는다.

## 서버 교체 및 운영 범위

기본 서버 https://router.project-osrm.org 는 개발용 공개 데모다. 합리적인 비상업 용도, 초당 1회 이하 정책이며 가용성·응답 시간·데이터 갱신을 보장하지 않는다. 클라이언트는 요청 간격 1.1초 이상, 타임아웃, 취소, 오류·NoRoute·NoSegment 처리를 적용한다. 오프라인 길찾기와 실시간 교통은 제공하지 않는다.

배포 시 직접 운영하거나 사용 계약이 있는 OSRM 호환 서버로 바꾼다:
`./gradlew :app:assembleRelease -ProutingBaseUrl=https://your-osrm.example`

경로 탐색 시 현재 좌표와 목적지를 해당 HTTPS 서버로 전송한다. 이동 이력은 저장하지 않는다. 지도 타일은 앱 식별 User-Agent, HTTP 캐시, 화면 영역 요청 및 표시된 OSM 크레딧을 유지한다.

- OSRM API: https://project-osrm.org/docs/v26.4.0/http
- 공개 서버 정책: https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server
- OSM 타일 정책: https://operations.osmfoundation.org/policies/tiles/
- Pleos 위치 SDK: https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/FusedLocation/intro
